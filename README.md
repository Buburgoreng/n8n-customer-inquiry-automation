# Customer Inquiry Automation System

## 1. Project Overview
An automated customer inquiry handling system built using n8n.

The system receives customer inquiries through an online form, sends notifications to the administrator, and automatically sends confirmation emails to customers.

## 2. Business Problem
Manually handling customer inquiries can cause:
- Slow response times.
- Missed customer inquiries.
- Repetitive administrative work.
- Lack of immediate confirmation for customers.

## 3. Proposed Solution
This automation system streamlines the inquiry process by:
- Collecting customer information through an online form.
- Sending inquiry notifications to the administrator.
- Sending automatic confirmation emails to customers.

## 4. Workflow Architecture
Customer Form → n8n Form Trigger → Email Notifications

## 5. Form Fields
- Full Name
- Email Address
- Company Name
- Message

## 6. Tools & Technologies
- n8n
- Gmail
- Google OAuth2
- Email Automation

## 7. Business Benefits
- Reduces repetitive administrative tasks.
- Improves inquiry handling efficiency.
- Provides immediate customer confirmation.
- Helps administrators receive inquiries consistently.
